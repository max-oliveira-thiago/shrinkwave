# Shrink Wave

Shrink Wave is a React and TypeScript web application that automates workflows for therapists, consultants, and other professionals. It helps reduce manual tasks so you can focus on delivering value to your clients.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
   This runs Vite in development mode and serves the app on `http://localhost:8080` by default.

## Building for Production

Create an optimized build with:
```bash
npm run build
```
The compiled files will be output to the `dist` directory. You can preview the build locally with:
```bash
npm run preview
```

## Linting

Check the project with ESLint:
```bash
npm run lint
```

---

With these commands you can develop, test and deploy the Shrink Wave application.
