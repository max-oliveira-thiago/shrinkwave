# Shrink Wave

Shrink Wave is a web application that automates routine tasks for therapists, consultants, coaches, and legal professionals. It helps reduce no-shows, streamline proposal delivery, and manage sessions so professionals can focus on their clients.

The frontend is built with Vite and React using TypeScript, Tailwind CSS, and components from shadcn/ui and Radix UI. React Router and React Query round out the stack, providing a modern, responsive experience.
